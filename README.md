# phoxal.com

Static public website for Phoxal Framework.

- `index.html`: North Star-led public project page
- `styles.css` and `assets/`: presentation

The homepage communicates Phoxal's enduring direction and principles.
It must not become an inventory of current repositories, packages, APIs, supported backends, or implementation status.

The site is intentionally small while the pre-1.0 product and implementation continue to evolve.

Developer installation belongs to the [Cargo tool documentation](https://github.com/phoxal/cargo#installation).
Native simulation setup belongs to the [simulator documentation](https://github.com/phoxal/simulator#readme).
